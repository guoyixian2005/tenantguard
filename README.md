# Project05_海外房东验真工具 (TenantGuard AI / VeriRent)

> 一句话说明：专为海外独立小房东（1~5 套房）打造的租客工资单（Paystub）与银行流水（Bank Statement）反欺诈快检工具。

## 状态

进行中 (需求定义与 MVP 准备阶段)

## 项目背景与核心价值

- **目标客群**：美国、加拿大、英国、澳洲的 DIY 独立小房东（Small Independent Landlords，管理 1~5 套物业）。
- **解决痛点**：传统驱逐老赖流程耗时长达 6~12 个月、经济损失破万；市面防伪工具（Snappt 等）仅面向大型商业物业公司、门槛高昂且不对个人开放；传统信用背调平台无法识别 Photoshop / 在线假工资单生成器伪造的文件。
- **产品解法**：轻量级网页端自检工具。房东只需上传租客提交的 PDF 工资单或银行对账单，系统通过元数据溯源、数学算式逻辑校验、税率倒推与布局排版分析，1 分钟内生成包含 0~100 风险评级与红旗警示（Red Flags）的核验报告。
