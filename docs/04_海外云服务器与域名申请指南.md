# 海外云服务器与域名申请与配置实操指南

> **适用场景**：国内开发者/创业者出海（如 TenantGuard AI 项目），无需国内 ICP 备案，直接面向欧美客户提供低延迟服务。

---

## 一、 为什么不能直接用国内服务器和域名？

1. **监管与备案壁垒**：国内服务器必须做 ICP 备案和公安备案，无法直接绑定境外未备案域名对外服务；
2. **访问延迟与网络抖动**：国内服务器到欧美物理距离远且经过国际出口网关，欧美用户访问延迟高达 200~400ms，甚至经常丢包；
3. **商业信任度**：欧美用户对网站证书、IP 归属地极其敏感，部署在境外机房（如美西/美东）是建立商业信任的基本前提。

---

## 二、 境外域名（Domain）购买流程

### 1. 推荐注册商（按上手门槛排序）

| 注册商 | 支付方式 | 核心优势 | 推荐指数 |
| :--- | :--- | :--- | :--- |
| **Cloudflare Registrar** | 国际信用卡 / PayPal | 零加价原价续费，自带全球最顶级免费 DNS 与 CDN 防护 | ★★★★★（首选） |
| **Namecheap** | 支付宝 / 微信 / 信用卡 | 国际知名老牌，支持支付宝付款，赠送终身免费 Privacy 隐私保护 | ★★★★☆（无外卡首选） |
| **Namesilo** | 支付宝 / 微信 / 信用卡 | 价格便宜透明，支持支付宝，免费 Whois 保护 | ★★★★☆ |
| **Porkbun** | 支付宝 / 信用卡 | 界面友好轻量，.com/.ai 价格极具竞争力 | ★★★★☆ |

### 2. 实操步骤（以 Namecheap / Cloudflare 为例）
1. **准备工作**：一个境外常用邮箱（推荐 Gmail 或 Outlook，避免使用 QQ/163 邮箱）。
2. **域名挑选**：
   - 建议优先选择 `.com`（商业信任度最高），其次为 `.ai` 或 `.io`（科技/工具属性强）。
   - 品牌命名建议：简单好记（如 `tenantguard.ai`, `checkpaystub.com`, `verirent.co`）。
3. **选购与下单**：
   - 访问注册商官网，搜索域名并加入购物车；
   - **务必确认勾选 `Domain Privacy / WhoisGuard`（免费隐私保护）**，防止个人真实姓名、邮箱和地址被公开抓取；
   - 选择付款方式（无双币信用卡选支付宝 Alipay，有双币卡选 Credit Card）。
4. **DNS 托管建议**：
   - 购买完成后，将域名的 Nameservers（NS 记录）统一修改指向 **Cloudflare**，由 Cloudflare 免费提供全球 Anycast 加速、一键开启免费 SSL 证书及抗 DDoS 防护。

## 三、 境外服务器（Server / Hosting）选型与申请

针对不同架构，推荐两种最具性价比的部署方案：

### 方案 A：Serverless / 静态前端托管（零服务器运维，首选推荐）
如果你的产品初期是前端静态页（如我们的 `web/index.html`）或 Next.js 全栈应用：
- **推荐平台**：**Vercel** 或 **Cloudflare Pages**
- **费用**：**完全免费**（个人版提供每月充足的流量与无服务函数调用额度）。
- **优势**：
  - 无需购买任何 Linux VPS，无需配置 Nginx、SSL 证书或系统补丁；
  - 自动分配全球 Anycast CDN 节点，欧美用户秒级加载；
  - 绑定自定义域名后自动签发 HTTPS 证书。

---

### 方案 B：独立 VPS 云服务器（需运行 Python 核心算法与数据库）
如果需要长期运行 Python 深度检测分析服务、持久化存储或自定义服务：

#### 1. 推荐服务商对比

| 云厂商 | 支付方式 | 价格区间 | 推荐机房节点 | 特点 |
| :--- | :--- | :--- | :--- | :--- |
| **腾讯云海外轻量 / 阿里云国际** | 微信 / 支付宝 | 约 24~35 元/月 | 硅谷 (Silicon Valley) / 弗吉尼亚 (Virginia) | 无需外币卡，中文后台极易上手，免备案 |
| **DigitalOcean / Linode** | 双币信用卡 / PayPal | $4 ~ $6 / 月 | 纽约 (NYC) / 旧金山 (SFO) | 开发者口碑标杆，控制台清爽，支持快照备份 |
| **AWS Lightsail** | 双币信用卡 | $3.50 ~ $5 / 月 | 美东 (俄亥俄/北弗) / 美西 (俄勒冈) | 亚马逊旗下轻量 VPS，网络骨干极度稳定 |
| **RackNerd / 搬瓦工** | 支付宝 / 银联 | $15 ~ $30 / 年 (促销款) | 洛杉矶 / 圣何塞 | 极致性价比，适合初期低成本试水 |

#### 2. VPS 购买与配置流程
1. **注册账号**：使用 Gmail 注册，填写基本资料；
2. **选择规格**：
   - 操作系统：**Ubuntu 22.04 LTS** 或 **Ubuntu 24.04 LTS**（社区生态最成熟）；
   - 配置：基础测试 1核 1G 内存（1 vCPU / 1GB RAM / 20GB SSD）足矣；
   - **机房位置（极其重要）**：必须选择 **United States (US West - San Jose/Silicon Valley 或 US East - Virginia)**，贴近目标欧美小房东客群。
3. **完成支付**：选择信用卡或支付宝结算；
4. **安全配置**：
   - 开通安全组（防火墙）：开放 `22` (SSH)、`80` (HTTP)、`443` (HTTPS) 端口；
   - 使用终端 SSH 登录连接：`ssh root@<你的公网IP>`。

## 四、 必备基础工具与付款方式解决方案

国内个人开发者出海最常见的卡点是**外币支付**，三种解决路径：
1. **国内银行双币/全币种信用卡（最省心）**：
   - 招商银行、工商银行、中国银行、建设银行均可手机银行 App 申请 Visa/Mastercard 信用卡（学生或无工作者可办 VISA 单币借记卡/莫奈卡）。
2. **国内注册国际版 PayPal**：
   - 访问 PayPal 中国官网注册个人账号，直接绑定国内银联借记卡或信用卡，可支付 90% 境外服务（如 Namecheap、DigitalOcean）。
3. **全走支付宝通道**：
   - 域名选 **Namecheap / Namesilo**；
   - 服务器选 **腾讯云海外轻量（硅谷节点）/ 阿里云国际版 / RackNerd**。
   - 全程无需任何外币卡，直接人民币微信/支付宝扫码扣款。

## 五、 标准上线部署操作路径（从 0 到 1 串联）

```
1. Namecheap 购买域名 (支付宝支付)
       ↓
2. 修改域名 NS 记录，托管到 Cloudflare (免费)
       ↓
3. 购买美区 VPS (腾讯云海外轻量或 AWS Lightsail)
       ↓
4. Cloudflare DNS 解析：添加 A 记录指向 VPS 公网 IP
       ↓
5. 开启 Cloudflare 小黄云 (CDN 加速 + 自动免费 SSL 证书)
       ↓
6. VPS 上拉取代码，运行 Python 验真服务与 Nginx 反向代理
```
