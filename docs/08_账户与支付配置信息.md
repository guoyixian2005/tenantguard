## 三、 Stripe 提现绑定手把手对照步骤

1. 登录 Stripe 控制台：`dashboard.stripe.com`；
2. 搜索或进入：**Settings (设置) ➔ Bank accounts and scheduling (银行账户与提现周期)**；
3. 点击 **+ Add bank account (添加银行账户)**；
4. 对照上表填写：
   - Routing number 填：`031100209`
   - Account number 填：`70581370002675529`
   - Confirm account number 再填一次：`70581370002675529`
5. 点击 Save 保存，Stripe 就会将赚到的美元自动清算入账到你的 Citibank (Payoneer) 账户！
